# YT_CLEAR

Recopilación de filtros de uBlock Origin para mejorar la experiencia en YouTube y ayudar a concentrarse en el contenido.

**Aviso:** No soy el creador de los filtros. Este repositorio es solo una recopilación pensada para organizar y facilitar su uso, y ayudar a que otros los encuentren más fácilmente.

Incluye filtros para:
- Ocultar feeds, animaciones y botones innecesarios.
- Mejorar la experiencia en PCs de bajos recursos.

Para complementar esta colección, se pueden usar también los filtros del repositorio "ublock-hide-yt-shorts" de gijsdev, que ayudan a ocultar los videos Shorts en YouTube: https://github.com/gijsdev/ublock-hide-yt-shorts

**Uso:** Usar con [uBlock Origin](https://github.com/gorhill/uBlock).
